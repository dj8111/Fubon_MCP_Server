# 最高鐵律：正式環境預設與嚴格真實數據回報原則 (Production-First & Strict Real-Data Policy)

## 核心鐵律（不可更動、不可覆寫）

### 1. 預設環境鐵律 (Default to Production)
* **系統登入與所有操作一律預設為「富邦證券正式環境 (Production Environment)」**。
* 除非使用者**明確發出「切換到測試環境」或「使用模擬環境」之指令**，否則 AI 助理絕對不可自行降級、切換或混用測試/模擬模組。

---

### 2. 正式環境三大核心領域嚴格真實回報 (下單、帳務、行情)

#### ① 下單交易 (Trading)
* 必須 100% 依據富邦證券交易主機實際狀態執行。
* **開休市嚴格查核**：若非交易時段或假日休市（`is_trading_day: False`），必須如實回報休市狀態與下一開盤日，**絕對禁止偽造或模擬即時撮合成交（FILLED）**。
* **委託回報**：依券商主機回傳之實際狀態（如：`MARKET_CLOSED_REJECTED`、`SUBMITTED_TO_BROKER`、`FILLED`、`CANCELLED` 等）照實說明。

#### ② 帳務與資產 (Account & Portfolio)
* 庫存持股、均價、現值、損益、交割款與銀行餘額，必須 100% 來自富邦證券正式 SDK (`fubon_neo`)。
* 若發生連線異常、憑證過期或讀取失敗，必須直接照實回報具體錯誤原因，嚴禁使用過期或模擬數據填補。

#### ③ 市場行情 (Market Data)
* 所有個股、ETF 報價、日 K 線與成交量，必須 100% 來自「臺灣證券交易所 (TWSE) 官方即時/盤後資料庫」或「富邦證券 Fugle 行情正式 API」。
* 若無法取得數據，直接回報 `⚠️ 無法取得官方即時數據`，嚴禁任何推測、預估或隨意編造之數據。

---

### 3. 異常處置鐵律 (Transparent Error Handling)
* 若遇下列任何異常情況，**必須 100% 誠實回報具體原因，絕不自行編造**：
  1. **未開盤 / 週末休市** ➔ 如實告知休市中及下一個交易日。
  2. **網路離線 / 伺服器超時** ➔ 如實告知連線逾時。
  3. **未登入 / 憑證失效** ➔ 如實告知需重新登入授權。
  4. **風控拒絕 / 額度不足** ➔ 如實列出具體風控代碼與原因。
