# 富邦即時購買力與待交割款計算準則 (Buying Power & Settlement Calculation Rule)

## 核心計算公式
在查詢、試算或回報使用者之「即時購買力 / 買進額度 / 帳戶現金可用金額」時，必須嚴格遵守以下公式：

$$\mathbf{實質即時可用購買力} = \mathbf{台北富邦銀行可用餘額} - \mathbf{尚未交割之應付交割款項} - \mathbf{圈存預扣金額}$$

## 規則細節與執行準則
1. **台北富邦銀行可用餘額 (Available Balance)**：
   - 來自富邦證券交割銀行帳戶之即時可用餘額 (`sdk.accounting.bank_remain`)。
2. **尚未交割款項 (Unsettled / Pending Settlement)**：
   - 包含所有 T+2 尚未到達交割扣款日之買進待扣交割款（來自 `query_settlement` 之應付金額）。
   - 在交割扣款前，此款項仍暫存於銀行帳戶，但不可再重複作為買進額度使用，必須全額扣除，以防違約交割。
3. **圈存預扣金額 (Pre-save / Stock Freeze Amount)**：
   - 當日圈存交易或委託預扣之金額，亦須全額扣除。
4. **輸出呈現規範**：
   - 每次回報購買力或餘額時，必須清晰條列：
     - 🏛️ **台北富邦銀行可用餘額**
     - ⏳ **尚未交割之應付交割款** (註記交割日與標的)
     - 🔒 **圈存預扣金額**
     - ⚡ **實質即時可用購買力** (明確展示扣除計算式)
